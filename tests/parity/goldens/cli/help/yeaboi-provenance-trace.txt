usage: yeaboi provenance trace [-h] [--depth N] [--format {text,json}] ENTITY

Every deterministic signal yeaboi surfaces (practice nudges, blocker flags,
confidence adjustments, conflict cards, performance preps and reviews) is
recorded in a tamper-evident hash chain with its evidence. This command
verifies and reads that chain — deterministic, local, no LLM involved.

positional arguments:
  ENTITY                Entity id, as listed by `yeaboi provenance audit`

options:
  -h, --help            show this help message and exit
  --depth N             Evidence hops to follow (default 2)
  --format {text,json}  Output format
